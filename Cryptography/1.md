## Challenge

```bash
from itertools import cycle

flag = b"flaggg{????????????????????????????????????????}"
# len(flag) = 48
key  = b'djpakoda'
# len(key) = 8
ct = bytes(x ^ y for x, y in zip(flag, cycle(key)))

with open("ct", "wb") as ct_file:
    ct_file.write(ct)
```

## Solution

Decryption is the same operation as encryption: XOR the ciphertext

```bash
from itertools import cycle
KNOWN_KEY = b'djpakoda'
try:
    with open("ct", "rb") as f:
        CIPHERTEXT = f.read()
except FileNotFoundError:
    print("ERROR: Could not find 'ct' file.")
    exit()
decrypted_bytes = bytes(x ^ y for x, y in zip(CIPHERTEXT, cycle(KNOWN_KEY)))

print("Flag:", decrypted_bytes)
```
Flag: `flaggg{w0w_g0od_j0b_V3ry_gr34t_amazing_AW35OMEE}`
